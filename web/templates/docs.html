The one-paragraph version

Alibi reads the documents a student actually has — syllabus PDFs, a WhatsApp export, a photographed notice board, an ERP screen, an ICS feed — and turns them into an evidence-backed ledger of commitments. A model reads and drafts; deterministic code verifies, computes, decides and remembers. Every claim carries the verbatim span that justifies it, so the system can answer "why do you believe this" and can prove that nothing unverified ever became trusted state.

What is NOT here

No multi-agent theatre, no fine-tuning, no blockchain notary, no RAG chatbot, no "AI plans your week". Each would be decoration on a system whose only defensible claim is that its numbers are checkable. Where an LLM is used, it is because the task is language; where it is not, it is absent, and the UI says which engine produced each row.
