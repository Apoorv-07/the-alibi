What the browser can see

Nothing secret: {{ cfg | tojson }} is the whole configuration surface this page receives, and it is the output of a redacting view — keys are printed as presence booleans, never values. No token is ever embedded in a page, a form, or a script tag; the API keys live in this process's environment only.
